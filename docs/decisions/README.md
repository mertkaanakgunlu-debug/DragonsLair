# Karar kayıtları

**Tek geçerli açık karar listesi:** [GDD §12](../game-design/GDD.md#12-açık-karar-defteri--arkadaşın-yanıtı-beklenecek). Aynı tabloyu burada çoğaltıp iki ayrı kaynağa dönüştürmeyin.

Bu klasör, kullanıcı ve fikrin sahibi arkadaş tarafından onaylanacak önemli **ADR (Architecture/Design Decision Record)** belgelerini saklamak içindir. İlk ADR henüz yok. Kararların durumu: OPEN / PROPOSED / APPROVED / DEFERRED / REJECTED.

ADR açılınca şablon:
- ID / başlık / tarih / durum / onaylayan
- Sorun ve gereksinimler
- Değerlendirilen seçenekler ile artı/eksi
- Gerekçeli karar veya açık soru
- Sonuçlar, geri dönüş maliyeti, etkilenen GDD başlığı ve Issue

**Açık kararlar otomatik onay sayılmaz.** Özellikle D-001 tek ejderha mı takım mı hibrit mi, D-003 kamera/hareket, D-004 2D/3D, D-005 motor, D-006 evrim, D-010 fikrî mülkiyet ve yayın sahipliği açık kalır. Tasarım sahibinin cevabı gelmediyse OPEN tutulur.
