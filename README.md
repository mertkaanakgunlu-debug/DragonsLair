# DragonsLair

**Durum:** Başlangıç kurulumu — tasarım ve kapsam onayı bekleniyor.

Bu depo, [Stickman Defense: Survival TD](https://play.google.com/store/apps/details?id=com.thp020.stickman.casual.war.game) oyununun genel roguelike/savunma mekaniklerinden ilham alan, **özgün** ejderha temalı bir mobil oyun projesi içindir. Referans oyunun kodu, varlıkları ve ayırt edici görsel ifadesi kopyalanmayacaktır.

**Ürün ilkesi:** Gameplay-first. Mağaradaki yavru ejderhanın giderek güçlenmesi ve ilerleyen aşamalarda insan akıncılarına karşı yuvasını savunması; diyaloglar veya zorunlu ara sahnelerle değil, oynanış ve düşman ilerlemesiyle hissettirilir.

Şu an **geliştirme fazı başlatılmadı**. GDD ve yol haritası onay bekleyen taslaktır. ChatGPT planlama ve bağımsız inceleme; Claude Projects koordinasyon; Claude Code uygulama; GitHub kanonik kaynak olarak kullanılır.

**Politika:** GitHub Actions/hosted CI yoktur; testler yereldir. `main` üzerinde onaysız geliştirme ve PR merge yapılmaz.
